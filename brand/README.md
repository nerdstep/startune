# Brand

The StarTune logo is the scanned star: a lime five-point star inside scanner corners, followed by
the "StarTune" wordmark in Geist SemiBold. The live version is the `Logo` component in
[src/components/shell.tsx](../src/components/shell.tsx). The script below also writes the
favicon, app icons and web manifest into [public/](../public/).

| File | Use it on |
| --- | --- |
| `startune-banner.svg` | The README heading. The social card's star field, logo and tagline in a 1280 × 180 strip with a hairline edge, so it reads the same on light and dark pages. |
| `startune-logo-card.svg` | Anywhere else you can't control the background. The logo on its own dark card with a hairline edge. |
| `startune-logo.svg` | Dark backgrounds. Transparent, off-white wordmark, as in the app. |
| `startune-logo-light.svg` | Light backgrounds. The mark sits on its black tile, so the lime never touches white; black wordmark. |
| `startune-social.svg` | 1280 × 640 card with the tagline over a field of class-coloured stars. |
| `startune-social.png` | The same card as a PNG, for GitHub's social preview (Settings → General → Social preview). |

In the SVGs the wordmark is converted to outlines, so the files look the same on machines without
Geist installed. Don't use the light-text version on white: the wordmark disappears.

The banner and the card have their own background rather than switching logos with `<picture>`, because GitHub picks the `<picture>` source from the operating system's color scheme, not from the GitHub theme. With GitHub set to light on a dark OS, the light-text logo lands on a white page.

## Regenerating

The SVGs are generated by `make_logo.py` from the Geist font in `node_modules`, using the app's
exact type settings (size, weight, letter-spacing, OpenType features). To change the logo, edit the
constants at the top of the script and run it again. Keep the mark geometry in step with
`MARK_STAR` and `MARK_CORNERS` in `shell.tsx`.

The same run renders the app icons into `public/`, with resvg:

| File | What it is |
| --- | --- |
| `favicon.svg`, `favicon.ico` | The mark on its Black Field tile; the `.ico` holds 16, 32 and 48px. The frame is thickened slightly so it holds at 16px. |
| `icon-192.png`, `icon-512.png` | The same tile at the mark's own weight (manifest `any`). |
| `apple-touch-icon.png` | 180px, full-bleed: iOS rounds the corners itself, so the mark has more room. |
| `icon-maskable-512.png` | Full-bleed, with the mark inside Android's 80% safe zone (manifest `maskable`). |
| `site.webmanifest` | Name, colours and the three icons above. |

The tile's corner radius is concentric with the frame's rounded corners (`tile_mark` explains
the arithmetic), so the two curves run parallel.

```sh
bun install                      # provides the Geist font
python -m venv .venv
.venv/Scripts/pip install -r brand/requirements.txt   # macOS/Linux: .venv/bin/pip
.venv/Scripts/python brand/make_logo.py
```

There's no PNG step in the script. To refresh `startune-social.png`, open `startune-social.svg` in
a browser window sized to 1280 × 640 and take a screenshot, or run
`inkscape brand/startune-social.svg -o brand/startune-social.png`.
